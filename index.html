Policy Requirements

Per NovaPay AUP v2.1, §4.1 — All Authorized Users must protect access credentials to the following minimum standard:

  • Minimum 14 characters Longer passwords exponentially increase brute-force resistance
  • At least 1 uppercase letter (A–Z) Expands the character search space for attackers
  • At least 1 lowercase letter (a–z) Required for mixed-case complexity
  • At least 2 numeric digits (0–9) Numeric characters add character set diversity
  • At least 2 special characters e.g. ! @ # $ % ^ & * ( ) _ + - = [ ] { }
  • No 4+ consecutive identical characters Prevents trivially guessable patterns (e.g. "aaaa")
  • No common keyboard sequences e.g. "qwerty", "12345", "abcde", "asdf"
  • Not a commonly breached password Checked against known weak passwords from breach databases
  • Minimum 60 bits of entropy NIST SP 800-63B recommended entropy threshold
